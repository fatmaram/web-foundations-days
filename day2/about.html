About QuickNotes

QuickNotes is a simple app for capturing ideas fast. It keeps your notes in one place so you can find them later.

How to use QuickNotes

  1. Open the app and click New Note.
  2. Type your idea in the note box.
  3. Press Save to keep the note.

Features

  • Fast note capture
  • Simple search
  • Clean layout

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
